課文・第四課

我和媽媽逛商場

星期天中午，我和媽媽一起逛商場。商場裏面的人真多呀！有的人在買衣服，有的人在看鞋子，還有的人在挑玩具。

媽媽想給我買一件毛衣。媽媽認真地看，仔細地挑。毛衣有的太大，有的太小，有的顏色太深，有的顏色太淺。最後，我們買了一件綠色的毛衣。我們逛商場逛得很開心。

四幕玩法

  1. 出發逛商場：拖著小主角走到商場，路上撿 3 顆心心。
  2. 熱鬧的商場：點出正在買衣服、看鞋子、挑玩具的人。
  3. 仔細挑毛衣：點毛衣聽媽媽的評語，把不合適的放回架上。
  4. 穿上新毛衣：把綠色毛衣拖到小主角身上，再合照一張。

操作：手機直接拖曳與點按；桌面用滑鼠，也可以按 ← → 或 A、D 走路。
