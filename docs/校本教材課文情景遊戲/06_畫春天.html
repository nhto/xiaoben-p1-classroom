畫春天

huà chūn tiān

今天，爸爸送我一盒彩色筆。
翻開這一頁，我們一句一句，把春天畫出來。

畫好了

第三頁 · 疊詞與顏色

草地、大樹與花

再畫一片綠油油的草地，還有高高的樹，五顏六色的花。

畫好了
點一點草地，讓它變成綠油油。
第四頁 · 方位詞

送小動物回家

小燕子在天空上飛，小鴨子在水裏游泳，小白兔在草地上跑。

畫好了
先點一隻小動物，再點牠住的地方。

全文朗讀

普通話

給老師和家長

這不是一個題庫，而是一本由孩子親手畫完的繪本。

產品定位

把《畫春天》的七句話，畫成五頁繪本。孩子一打開就開始玩，一頁畫好，翻到下一頁，不用選關、不會迷路：把顏色筆放回格子、描出圓圓的太陽、點出綠油油的草地、送小燕子、小鴨子和小白兔回家、按順序點亮彩虹，最後聽一遍全文朗讀。

每一頁都是「先動手畫，再答一題」：畫好後出現一道簡單問答，答對才翻頁。題目只考課文讀懂了沒有（誰送的、先畫甚麼、花是甚麼顏色、小鴨子在哪裏游泳、彩虹掛在哪裏），答錯不扣分，會再讀一次課文原句給孩子聽。

  • 對象：小一至小二，香港繁體字教材。
  • 場景：課堂投影全班玩、平板個人練習、家中親子共讀。
  • 四條原則：以畫驗讀、聽覺先行、沒有失敗、一句一畫面。
  • 流程：封面 → 五頁繪本（順序固定）→ 全文朗讀；每頁畫好、答對後按「下一頁」繼續，也可停下來多看一會，不會自動跳頁。

五頁與學習點

頁動手做學習點
1 彩色筆點筆、點顏色格；答「誰送彩色筆」紅、橙、黃、綠、青、藍、紫；誰
2 太陽沿虛線描圓；答「先畫甚麼」圓圓的；先……再……
3 草地點草地、點大樹、點開五朵花；答「花的顏色」綠油油、高高的、五顏六色
4 動物的家送小燕子、小鴨子、小白兔回家；答「小鴨子在哪裏游泳」在……上／裏；三種動物
5 彩虹按課文顏色順序點亮七條弧線；答「彩虹掛在哪裏」顏色順序與全篇回顧

插畫風格

全篇為卡通兒童繪本風：奶油紙色、手繪不規則線條、水彩般的柔和色塊、紙張顆粒，加上會微笑的太陽、花兒與小動物。插畫全部以內嵌 SVG 手繪，不載入外部圖片，離線也完整。

音效設計

聲音分三層：操作層（點選、翻頁、放筆）、反饋層（正確、提示、完成）、朗讀層（題目、句子與全文普通話朗讀）。錯誤提示用柔和的下降音，不用警報聲；音效短促，避免蓋住朗讀，也可隨時用右上角按鈕關閉。

全文朗讀

第五頁答對後按「聽全文」進入「全文朗讀」：逐句高亮、拼音可開關、0.8 倍慢速、點任何一句可重聽。朗讀使用瀏覽器內建的普通話語音；裝置未安裝普通話語音時，會提示改用系統語音，或跟隨高亮文字朗讀。

用字依據

全篇用字以《香港小學學習字詞表》為校對依據，例如「水裏」用「裏」不用「裡」、「沿着」用「着」、「甚麼」不用「什麼」；「顏色」「游泳」「彩虹」「誇」等依香港常用字形。課文句子保持原貌，關卡提示語另用淺白短句。

實現方式

單一 HTML 檔案，離線可玩；音效用 Web Audio 即時合成，不載入外部音檔；動畫以 CSS 與 SVG 為主。版面按裝置自動重排：手機直向是單欄大圖，電腦與平板橫向改成「左圖右文」的雙欄，橫放手機則用精簡雙欄；同一個檔案，不需另做 App。遊戲不收集、不上傳任何個人資料；重新載入頁面即由封面開始。
